# Сравнение Git и SVN

## 1. Почему в Git ветвление дешёвое, а в SVN дорогое?

В Git ветки создаются быстро, поскольку ветка представляет
собой указатель на коммит. Для создания ветки не требуется
копировать файлы проекта.

В SVN ветки создаются через копирование каталогов
в репозитории. Само копирование обычно дешёвое,
но дальнейшая работа с ветками и их слияние
могут быть сложнее.

## 2. Можно ли в SVN сделать коммит без интернета? Почему?

Для коммита SVN требуется соединение с центральным
сервером репозитория.

Если сервер недоступен, выполнить коммит нельзя.
Однако интернет не обязателен, если SVN-сервер
доступен по локальной сети.

В Git коммиты можно создавать полностью локально.

## 3. Когда SVN может быть предпочтительнее Git?

SVN может использоваться в старых корпоративных проектах,
где инфраструктура уже построена вокруг SVN.

Он также бывает удобен при необходимости централизованного
управления доступом к отдельным каталогам репозитория.

Переход на Git в таких проектах может потребовать
дополнительных затрат и изменения рабочих процессов.
